AHWS WEBSITE CONTENT FOLDERS
=============================

Place your actual content (images, videos, PDFs) in these folders.
Once you have added files here, let me know, and I will integrate them into the code for you!

- Images/Home_Page: Banners, features, slider images.
- Images/Ambassador: The transparent PNG of the Brand Ambassador.
- Images/Gallery: Real photos from events for the Gallery page.
- Videos/Home_Page_Hero: The actual world-school.mp4 or similar background video.
- Documents/Admission_PDFs: The actual PDF files for Age Criteria, Vendors list, etc.
- Documents/Events_and_Circulars: The Academic Calendar PDF and any circulars.
